# Scene Graph Schema

The `SceneGraph` object is the canonical output of VZT Video-Intel. Every consumer — Claude, your code, the CLI, downstream MCP tools — reads this shape.

Source of truth: [`src/schema/types.ts`](../src/schema/types.ts).

## Top-level

```ts
interface SceneGraph {
  source: string;            // Original video path or URL
  duration_ms?: number;      // Total video length in milliseconds
  scenes: Scene[];           // Detected scene boundaries
  transcript: TranscriptSegment[];
  entities: Entity[];
  actions: Action[];
  ocr: OcrRegion[];
  keyframes?: Keyframe[];    // Optional — only present when includeKeyframes=true
  chapters?: Chapter[];      // Optional — only present when generate_chapters was called
  perception?: PerceptionEvent[]; // Optional — only present from `observe`
  mux_base?: string | null;  // Optional Mux base URL for timestamp citation
  _warnings?: string[];      // Optional — non-fatal degradations (a backend failed, pipeline carried on)
  _pipeline: string;         // Comma-separated list of backends that ran
  _generated_at: string;     // ISO 8601 timestamp
  _version: string;          // Schema version (semver)
}
```

`_warnings` is how graceful degradation surfaces: if transcription or OCR fails, that stage comes back empty and the failure is recorded here instead of throwing. A `SceneGraph` with `_warnings` is still valid and usable — just partial.

## `Scene`

```ts
interface Scene {
  id: number;                // Unique within this scene graph
  start_ms: number;
  end_ms: number;
  shot_type?: "wide" | "medium" | "close" | "extreme_close" | "unknown";
  motion?: "static" | "panning" | "tracking" | "zoom" | "handheld" | "unknown";
}
```

Scene IDs are dense (0, 1, 2, …). The id is the foreign key from other elements (e.g. `Entity.appearances[].scene_id`, `Action.scene_id`).

## `TranscriptSegment`

```ts
interface TranscriptSegment {
  start_ms: number;
  end_ms: number;
  text: string;
  speaker?: string;         // "SPEAKER_00", "SPEAKER_01" if diarize=true
  confidence?: number;      // 0..1
  language?: string;        // ISO 639-1, populated on first segment
}
```

Segments are non-overlapping. Speaker labels are stable within one run but **not stable across runs** (Pyannote re-runs from scratch). If you need cross-video speaker continuity, pin speakers with the `minSpeakers` / `maxSpeakers` options.

## `Entity`

```ts
interface Entity {
  tracking_id: string;      // Stable across scenes within this run (e.g. "p1", "v3")
  label: string;            // "person", "car", "ball", … or whatever the prompt asked for
  confidence: number;       // 0..1
  appearances: {
    scene_id: number;
    start_ms: number;
    end_ms: number;
    bboxes?: { t_ms: number; bbox: [x: number, y: number, w: number, h: number] }[];
  }[];
}
```

The same `tracking_id` represents the same physical entity across scenes — that's the whole point of SAM2 tracking. Use this to answer "did the same person appear in scenes 0 and 3?".

`bboxes` are sampled, not dense. The default `sampleEveryMs` is 500ms per scene.

## `Action`

```ts
interface Action {
  scene_id: number;
  start_ms: number;
  end_ms: number;
  label: string;            // "running", "pointing at chart", "throwing", …
  actors?: string[];        // Entity tracking_ids that participate
  confidence: number;       // 0..1
}
```

Actions are generated by Qwen2.5-VL inspecting keyframes from each scene. Labels are free-text; for strict label sets, post-process with your own taxonomy.

## `OcrRegion`

```ts
interface OcrRegion {
  start_ms: number;
  end_ms: number;
  text: string;
  bbox: [x: number, y: number, w: number, h: number];
  language?: string;
  confidence?: number;
}
```

Sampled at `sampleEveryMs` (default 1000). Identical text in the same bbox across consecutive samples is **not** deduplicated — that's a v1.1 improvement. Treat overlapping samples as "the text was present during this window".

## `Keyframe`

```ts
interface Keyframe {
  scene_id: number;
  t_ms: number;
  jpeg_b64?: string;        // Base64-encoded JPEG
  width?: number;
  height?: number;
  caption?: string;         // Optional natural-language description from Qwen2.5-VL
}
```

When `perScene=true`, the keyframe is the midpoint of the scene. When `perScene=false`, frames are sampled every `intervalMs`.

## `Chapter`

```ts
interface Chapter {
  start_ms: number;
  end_ms: number;
  title: string;
  summary?: string;
}
```

Generated by `generate_chapters`. Chapters tile the video without gaps; the union of all chapters covers `duration_ms`. In lite mode there's no LLM — chapters are scene buckets titled by their first VLM caption.

## `PerceptionEvent`

```ts
type PerceptionKind = "hear" | "see" | "read" | "scene";

interface PerceptionEvent {
  t_ms: number;             // When it happens
  end_ms?: number;          // When it stops (for spans)
  kind: PerceptionKind;     // Which sense it came from
  text: string;             // What was heard / seen / read, or the scene label
  scene_id?: number;        // Set for `see` and `scene` events
  speaker?: string;         // Set for `hear` events when diarization ran
  confidence?: number;      // 0..1, when the source backend reports it
}
```

The output of `observe` — a single time-sorted track fusing all four senses:

- **`hear`** — a spoken transcript segment.
- **`see`** — a VLM caption of what's visually happening in a scene.
- **`read`** — on-screen text. Unlike raw `ocr[]` (one region per word per frame), `observe` condenses OCR into stable lines: words sharing a frame are joined top-to-bottom, and consecutive frames showing the same text merge into one span.
- **`scene`** — a shot/scene boundary marker.

Events are sorted by `t_ms`, then by sense priority (`scene` → `see` → `read` → `hear`) on ties. Hand `perception[]` to someone who can't watch the video and they'll know what happened, second by second.

## Working with timestamps

All timestamps are integer milliseconds, monotonic from 0. Convert to:

```ts
const seconds = ms / 1000;
const formatted = `${Math.floor(ms / 60000)}:${String(Math.floor(ms / 1000) % 60).padStart(2, "0")}`;
```

For Mux citation URLs, set `MUX_BASE_URL` (or pass `--mux-urls`) and use the helper at `src/lib/mux.ts`:

```ts
import { muxCitation } from "vzt-video-intel/lib/mux";
const url = muxCitation("https://stream.mux.com/abc.m3u8", 5400, 7200);
// → "https://stream.mux.com/abc.m3u8#t=5.40,7.20"
```
